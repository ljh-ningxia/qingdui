# 轻队 QingDui

面向大学生与小型团队（3–8 人）的轻量任务管理工具。按《轻队 QingDui PRD V1.0（正式版）》实现。

**一句话**：微信群负责说，轻队负责记住谁什么时候交。

---

## 怎么跑起来

需要 Node.js ≥ 22.5（内置 `node:sqlite`，不需要装任何依赖）。

### 方式一：双击（推荐）

双击 **`启动.bat`**，等 3 秒浏览器会自动打开 <http://127.0.0.1:3001>。

> **那个黑色命令行窗口不要关。** 关了服务就停了，网页也就打不开了。用完再关。
> 窗口里如果显示 `服务已停止`，说明服务掉了，重新双击一次即可。

### 方式二：命令行

```bash
node src/server/index.js 3001
```

同样要保持这个终端开着。

### 方式三：后台常驻（关掉终端也不停）

```bash
node daemon.js 3001
```

它会以脱离进程拉起服务，然后自己退出，日志写到 `server.log`。

> 如果你是在普通 Windows 桌面上跑，这个方式可以直接用。
> 如果在某些受限环境（比如被上层进程托管的终端）里跑，子进程可能被连带回收 —— 那就用方式一或方式二，保持窗口开着。

### 打不开怎么办

按顺序排查：

1. **先看黑窗口还在不在。** 窗口关了 = 服务停了，这是最常见的原因。
2. **看窗口里有没有报错。** 红字贴给我。
3. **端口被占**：换一个端口 `node src/server/index.js 3002`，然后访问 <http://127.0.0.1:3002>。
4. **确认真的在监听**：`netstat -ano | findstr 3001`，有 `LISTENING` 才对。

首次登录：输入任意 11 位手机号 → 点「获取验证码」→ 页面会直接显示验证码（本地开发模式）→ 点「直接填入」→ 登录。

> 手机号是加密存库的（AES-256-GCM + HMAC 盲索引），页面上显示为 `138****8000`。

## 已实现的关键行为

| 能力 | 说明 |
|---|---|
| 登录 | 手机号 + 6 位验证码，5 分钟有效、60 秒重发冷却、10 次/天、错 5 次锁 15 分钟 |
| 建组 | 免费版最多 3 个在用小组、8 人；邀请链接一键加入 |
| 任务 | 自然语言截止时间（今天 / 下周三 / 3天后 / 3月15日 / 2026-10-23T18:00） |
| 看板 | 四列拖拽（桌面 HTML5 DnD + 移动端长按 300ms）；列内 20 条分页，逾期横条全量 |
| 并发 | 乐观锁 `version`，冲突返回 409 + 最新数据；前端 2/4/8 秒重试后回滚 |
| 权限 | 负责人可编辑全组、组员只能改自己相关；均不能越权 |
| 动态流 | 只增不改不删，删除/恢复都留痕 |
| 提醒 | 站内红点 + 每日 08:30 汇总 + 24h/2h 高优 + 逾期次日 09:00 + `.ics` 写入手机日历 |
| 解散 | 解散后 30 天只读，仍可查看与导出，写入返回 403 |
| 导出 | CSV（带 BOM，Excel 直接打开）、`.ics`（含 `VALARM` 提前 1 天） |

## 两个必须说清楚的地方

**1. 短信是本地模拟的。** 本地开发模式下，验证码直接显示在登录页，不真发短信。频率控制、有效期、锁定逻辑与线上完全一致，只有「调用短信网关」这一步是桩。接真网关只需改 `src/server/api.js` 里 `sendSms()` 一处。

**2. H5 不能推送。** 这是 PRD 里就承认的结构性短板，所以提醒做了 4 层兜底：站内红点 → 每日汇总 → 逾期横条 → `.ics` 系统日历。最可靠的是最后一层，因为它不依赖用户打开网页。

## 配置

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `QD_PORT` | 3001 | 端口（也可 `node src/server/index.js 3111` 直接传） |
| `QD_DB` | `data/qingdui.db` | SQLite 路径，`:memory:` 为内存库 |
| `QD_SECRET` | 随机生成 | 会话与加密密钥，生产必须固定 |
| `QD_DEV_CODE` | `1` | 设为 `0` 关闭「页面显示验证码」，走真实短信 |
